# 🚀 **Learning Selenium Data-Driven Testing Framework**  

Welcome to the **Learning-Selenium-Data-Driven-Testing** repository! 📚 This repository is a hands-on guide to mastering **data-driven testing** with Selenium, TestNG, and the Apache POI library. Whether you're dealing with parameters, data providers, or Excel files, this repository has you covered! ✨  

---

## 🎯 **What’s Inside?**  

1. **Data-Driven Testing with TestNG Parameters** 📊  
   Learn to pass data directly to your test methods using XML-based parameters in TestNG.  

2. **Data-Driven Testing with TestNG DataProviders** 🧑‍💻  
   Master the `@DataProvider` annotation to supply multiple sets of data to your tests.  

3. **Data-Driven Testing with MS-Excel and Apache POI** 📂  
   Use the Apache POI library to read data from Excel files and integrate it into your test cases seamlessly.  

---

## 💻 **Getting Started**  

1. **Clone the Repository:**  
   ```bash  
   git clone https://github.com/Sassri24/Learning-Selenium-Data-Driven-Testing.git  
   ```  

2. **Import into Your IDE** (like IntelliJ IDEA or Eclipse).  

3. **Run the Examples** to explore how data-driven testing works with Selenium and TestNG. 🚀  

---

## 🌟 **Key Features**  

- Learn **TestNG Parameters** for XML-based data input.  
- Implement **TestNG DataProviders** for flexible and scalable data management.  
- Utilize **Apache POI** to handle Excel files for real-world data-driven testing.
